# 设计图索引

## 概览

共 17 个主要页面，使用内置 image_gen 生成。12 个创作及审查页面提供对应专业 agent 的右侧对话，另有 Agent 配置页面管理角色的模型、设定、Skills、MCP 与工具。图示没有接入真实运行能力。

专业角色规则见[专业 Agent 工作区](agent-workspaces.md)，具体页面操作见[页面规格](page-specifications.md)。未更改的项目首页、任务、服务和项目设置页面继续作为管理工作区，不强制添加创作聊天。

## 生成与校对

完整提示词见[prompts 索引](prompts/index.md)，文件、来源、角色及图像尺寸见[设计清单](design-manifest.json)。图片中的故事、日期、模型名称、费用和数字均为示例。

实现以功能文档为准，统一图标、品牌、快捷键和示例集数。工具来源按实际注册标明“内置”或“MCP”，不能从效果图中的统称推断；Skills 不授予权限。候选状态、角色运行状态和批准状态分别渲染，不能混为“在线”或“待指令”。

右侧对话只提交建议或制作请求。中央保留手工编辑、内容审查、采用候选与付费授权的独立操作。未获批的剪辑只能进行明确标注的预览导出，不能误标为正式成片。
