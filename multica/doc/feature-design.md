# 功能设计

## 概览

Multica 面向需要持续控制故事、人物、场景和制作成本的漫剧创作者。产品以项目、集、场次、镜头和共享资产组织工作，聊天用于描述当前对象的需求、提出修改和查看执行说明。

## 产品范围

第一版以个人导演主导的小规模制作闭环为目标，支持创建项目、整理故事、编写剧本、建立共享设定、审查分镜、制作关键帧和视频，以及剪辑导出。全剧可包含多集；每集独立管理剧本、镜头和成片。

产品不保证生成模型在每次调用中产生完全一致的像素结果。系统严格控制输入版本、授权范围、提交次数和制作状态；视觉与叙事质量由自动检查辅助人工审查。

## 导航层级

现有应用最左侧工具栏提供“漫剧”总入口，打开 Multica 全局工作台。全局工作台负责项目管理，项目工作台负责一部剧的规划和资产，单集工作区负责具体制作阶段。一个入口只承担一个范围。

```text
全局工作台
  全部项目 → 新建项目 / 进入项目 / 归档项目
  待我审查 → 跨项目审查队列
  生成任务 → 跨项目任务与费用状态
  模型与服务 → 供应商连接和能力配置
  Agent 配置 → 角色设定、skills、MCP 和工具范围
  设置 → 全局使用偏好

项目工作台
  全剧规划
    故事大纲
    分集规划
  共享设定库
    角色与造型
    场景
    道具
  分集制作
    第一集
    第二集
    …
  制作管理
    待我审查 → 预先筛选当前项目
    生成任务 → 预先筛选当前项目
  项目设置

单集工作区
  剧本 / 分镜 / 镜头制作 / 剪辑成片
  镜头制作：关键帧 / 视频
```

项目首页右上角提供“新建项目”。进入项目后，左上角提供“返回全部项目”，项目选择器提供最近项目、“全部项目”和“新建项目”。项目创建只建立数据，不自动调用生成服务。

左侧选中集数后，中央顶部的页签仅作用于这集。共享设定页和全剧规划页不显示单集制作页签。项目内不再增加全局“分集剧本”或“分镜台”重复入口。

全局审查、任务页与项目内入口使用同一套功能，通过项目筛选限定范围，不建立两套审查或任务记录。

## 制作流程

每个阶段产出可单独审查的版本。创作者可以导入已有素材或修改草稿；进入下一项制作任务前，系统验证所需输入已经批准。

| 阶段 | 主要产物 | 审查重点 | 依赖 |
| --- | --- | --- | --- |
| 项目创建 | 名称、构想、画幅、目标规模 | 制作方向与规模 | 无 |
| 全剧规划 | 故事大纲、人物弧线、分集规划 | 逻辑、节奏、铺垫与结尾 | 项目规格 |
| 单集剧本 | 场次、动作、对白、旁白 | 戏剧性、信息和预计时长 | 已批准分集规划 |
| 共享设定 | 角色、造型、场景、道具 | 可识别特征与可重复制作性 | 已确认的故事需求 |
| 分镜 | 景别、机位、动作、时长、粗构图 | 叙事可读性与连续性 | 剧本及相关设定版本 |
| 动态预演 | 粗分镜与临时声音组成的时间线 | 镜头长度、剪辑和对白节奏 | 分镜草稿或批准版本，明确标记用途 |
| 关键帧 | 正式图像、必要首尾帧 | 人物、构图、空间、道具 | 已批准分镜与生成授权 |
| 镜头视频 | 动态片段或有限动画 | 动作、表情、稳定性、口型 | 已批准输入画面与生成授权 |
| 声音与剪辑 | 配音、音效、字幕、剪辑版本 | 声画关系和整体节奏 | 明确引用的素材版本 |
| 成片 | 最终导出及素材清单 | 交付规格与最终审查 | 已批准剪辑版本 |

角色与场景设定可以伴随剧本细化；正式镜头制作需要固定实际引用的版本。动态预演用于低成本审查节奏，不视为正式成片。

## 一致性管理

共享设定保存稳定身份及不可变版本；镜头引用具体版本，不自动读取“最新版本”。系统保存镜头和产物对上游版本的依赖关系。

| 对象 | 内容 |
| --- | --- |
| 全剧设定 | 世界规则、时间线、人物关系、风格、信息揭示顺序 |
| 角色 | 外形特征、多视角参考、表情、左右利手、声音配置 |
| 造型 | 服装、发型、配饰及适用剧情范围，与角色身份分开 |
| 场景 | 门窗与固定物体布局、机位参考、灯光方案 |
| 道具 | 标准外观、状态版本、持有者及在镜头中的位置 |
| 镜头 | 剧本段落、引用资产、景别、动作、视线、对白、时长 |
| 产物 | 原件、预览、生成输入、有效参数、父版本和采用状态 |

镜头分别记录开始与结束状态，包括人物位置、面向、视线、左右手持物、衣服与伤势、道具状态、时间、天气及光线。检查报告应指出对象、镜头、时间点或图像区域，并说明对照的设定版本。

角色新版批准后，系统列出可能受影响的镜头和任务。创作者决定继续使用旧版、迁移指定镜头或放弃迁移。旧产物不被覆盖，也不自动触发新生成；发生迁移的镜头建立新草稿并进入复审。

自动检查区分“已确认冲突”“需要人工判断”和“未发现问题”。没有发现问题不代表质量已获批准。标准图之间的身份一致性也需要审查。

## 人工审查

三种决定分别保存，并绑定具体对象或请求版本。

| 决定 | 授权内容 | 不包含的授权 |
| --- | --- | --- |
| 内容定稿 | 认可某版大纲、剧本、设定或分镜 | 新的付费生成 |
| 制作授权 | 执行指定输入、参数、数量和额度的请求 | 采用生成结果或无限重试 |
| 结果采用 | 把某产物设为镜头正式素材 | 修改上游设定或执行后续生成 |

创作者可单项审查，也可明确选择多个对象批准。批量审查展示全部对象、版本、费用范围和异常项，不采用默认全选或隐式扩大范围。

生成单包含目标镜头、输入引用、有效提示词、供应商和模型、尺寸或时长、数量、修改范围、预估费用、授权上限、最多提交次数及失败策略。缺少可靠费用信息时，暂停需要费用控制的提交并要求完成服务费率配置。

授权绑定冻结后的请求。模型、参考素材、有效参数或数量改变后，重新申请授权。agent 无权批准自己的提案、扩大额度或直接将草稿设为定稿。

内容状态为“草稿 → 待审查 → 已批准”或“退回修改”；批准版本不直接编辑。引用变更可标记复审需求，迁移后创建新草稿。任务状态另行管理，不把任务成功等同于内容通过。

## 减少无效生成

优先以草图、素材复用和临时声音验证节奏，再制作正式关键帧，最后制作需要运动的镜头。静帧推拉、裁切、分层动画与生成视频可以混合使用。

局部返工明确修改区域、目标属性及保留内容。完成后重新检查保留区域，不能假定局部编辑一定不会影响其他内容。

每次失败记录分类原因，例如人物、造型、空间、动作、文字或画风偏差。下一次尝试先提交针对性修正方案；达到授权上限后停止，允许用户选择拆镜头、换方法或人工处理。

供应商能力影响可用参数。参考图、局部编辑、姿态、深度、首尾帧等功能仅在后端明确支持时展示；系统不静默丢弃不支持的约束，也不把 seed 视为角色身份或一致性证明。

## 协作与手工制作

支持人工修改剧本、导入标准图、上传外部修图和视频、调整时间线。人工素材进入相同的版本、来源和审查流程。

策划、编剧、角色设计、美术、分镜导演、生图、视频、连续性检查和剪辑角色使用共享项目数据。每个角色的职责、页面绑定和实际能力由[专业 Agent 工作区](agent-workspaces.md)定义，具体插件职责见[工程方案](architecture-design.md)。

## 专业助手与中央编辑区

创作页中央保留可手工编辑的表单、正文、资产、分镜或时间线，最右侧显示当前功能对应的专业 agent 对话。属性、引用和版本通过中央的紧凑页签或折叠区查看；同一页面不重复设置底部通用助手。

用户描述修改后，agent 提交结构化建议。用户查看前后差异，选择字段并应用到草稿；应用不等于定稿或付费授权。新建项目页的策划助手可以帮助填写表单，创建动作仍由用户单独确认。

切换页面、集数或镜头不会自动调用模型，也不改变在途任务的目标。角色分别保留工作记录，通过批准的版本化产物交接；页面与角色映射以[专业 Agent 工作区](agent-workspaces.md#页面与角色)为唯一配置说明。
