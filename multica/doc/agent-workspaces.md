# 专业 Agent 工作区

## 概览

每个创作页面的最右侧提供对应专业 agent 的对话面板。中央保持可手工编辑的表单、文档、画面或时间线；agent 根据当前对象提出结构化修改，由创作者选择应用到草稿。角色差异由实际角色设定、skills、MCP、工具和权限定义，不仅改变助手名称。

## 页面与角色

页面到角色的对应关系由宿主配置决定。分镜导演确定镜头表达和拍摄方案，生图与视频角色负责各自的实际制作方案。初期可以共享模型和代码包，但角色身份、工具授权和会话范围独立。

| 页面 | 角色 ID | 面板名称 | 主要 skills 示例 | 工具或 MCP 能力示例 |
| --- | --- | --- | --- | --- |
| 新建项目、故事大纲 | planner | 策划助手 | 创作定位、故事结构、人物弧线 | 读取项目草稿、提炼导入内容、提交字段或大纲提案 |
| 分集规划、单集剧本 | writer | 编剧助手 | 分集节奏、对白写作、角色语气、铺垫回收 | 读取剧本及设定、改写选中段落、提交跨集提案 |
| 角色与造型 | character-designer | 角色设计助手 | 角色一致性、造型、表情和标准图 | 读取参考图、准备图像制作请求、资产引用查询 |
| 场景、道具 | art-director | 美术助手 | 空间布局、灯光连续性、道具状态 | 读取场景及道具、提出机位与状态变更、准备参考图制作 |
| 分镜台 | storyboard-director | 分镜导演助手 | 镜头语言、机位、视线与动作衔接 | 读取批准剧本、提交镜头提案、准备构图草图 |
| 关键帧制作 | image-artist | 生图助手 | 参考图控制、局部修图、候选对照 | 读取参考图、准备生图请求、在授权范围内执行图像制作 |
| 视频制作 | video-director | 视频助手 | 动作编排、运镜、首尾帧控制 | 准备视频请求、在授权范围内提交、查询任务和候选片段 |
| 剪辑成片 | editor | 剪辑助手 | 叙事节奏、声画衔接、字幕和混音 | 读取时间线、提出裁切与声音修改、准备声音制作请求 |
| 待我审查 | continuity-reviewer | 连续性检查助手 | 剧情与视觉对照、镜头连续性 | 只读版本与媒体、提交检查报告；没有批准或应用修改工具 |

项目首页、生成任务、模型与服务、项目设置不强制增加创作聊天区。生成任务显示执行事实；配置页面由用户直接管理。需要解释时可打开上下文帮助，但不将运维或配置动作交给创作角色自动处理。

表中名称是产品能力示例，不表示已经安装某个 skill 或接入特定 MCP 服务。服务注册和实际工具列表必须经过能力校验；不可用的依赖明确显示原因。

## 对话面板

右侧面板由角色身份、对象上下文、对话记录、提案卡片和输入区组成。中央的属性、引用和版本信息通过紧凑页签、折叠区或弹层查看，不再额外堆叠一个永久属性栏。

| 部分 | 内容与行为 |
| --- | --- |
| 身份栏 | 明确显示策划助手、编剧助手等角色，配置版本及当前任务状态 |
| 对象栏 | 当前项目、集、场次、段落或镜头，目标对象版本和引用资料 |
| 能力与工具 | 折叠显示角色模型、skills、工具来源、MCP 连接状态和操作范围；链接到 Agent 配置 |
| 对话区 | 用户需求、专业解释、工具结果摘要、明确的修改提案 |
| 提案卡片 | 目标对象、前后差异、涉及字段、保留内容、引用版本和影响范围 |
| 输入区 | 文本、引用对象或附件、发送和运行时停止按钮 |

进入或切换页面只选择对应角色和上下文，不自动发送消息或调用模型。没有任务时显示“待指令”；产生提案后显示“建议待确认”；执行状态只对应真实任务。专业助手不需要模拟始终在线的工作人员。

输入区的用户草稿按工作区保存，切页不自动发送。停止按钮说明停止的是当前 agent 工作还是已提交媒体任务；远端取消结果通过生成任务页确认。

## 建议与修改

用户可以直接编辑中央内容，也可以在右侧描述目标。agent 读取明确选定的对象，返回基于该对象版本的提案。界面可以在中央预览拟修改字段，但预览不写入正式草稿。

操作顺序为：用户发出需求、agent 提出修改、用户查看差异、选择全部或部分字段、应用到草稿、按正常流程提交内容审查。忽略提案不会改变中央内容。

已经确认的字段可锁定。提案涉及锁定字段时明确标记，要求用户解锁或单独选择；不能通过“应用全部”静默覆盖。应用时重新校验目标版本，过期提案需要合并或重新生成，保留用户手工修改。

“应用建议”只应用选中的草稿修改，不等于内容定稿、创建项目、结果采用、付费生成或最终导出。生成类提案显示“查看生成单”和授权状态；用户在明确的制作授权操作中审查有效输入和费用。

审查页右侧 agent 只解释差异和检查结果。人工“批准此版本”“退回修改”等按钮位于中央审查操作区，与 agent 回复分开。自动检查报告没有批准权限。

新建项目使用独立的项目草稿身份。策划助手只能提出表单修改，直到用户点击“创建项目”才生成正式项目；使用对话助手的模型调用与创建动作分开计量和授权。

## 上下文和会话

工作区绑定包含项目或新项目草稿 ID、角色 ID、对象范围、角色配置版本及会话引用。故事规划可按项目聚合；剧本按集或场次绑定；视觉制作按角色、场景或镜头绑定。绑定规则明确配置，不仅用页面标题判断身份。

每次发送任务时冻结目标对象、目标版本、批准引用、选区、授权范围和配置版本。用户之后切页、换集或选择其他镜头，不会改变该在途任务的目标。返回结果归入原工作区，并提供跳转入口。

重新进入工作区恢复对应角色的记录和待处理提案。不同角色不共享一段可随时改写身份的无限聊天；需要共享的事实来自版本化项目对象或明确的交接摘要。原始闲聊不自动注入所有角色。

角色或配置版本改变时，由宿主建立或恢复正确配置的会话，不在已产生记录的 Session 中偷换 preset、角色权限或旧任务配置。既有在途任务继续固定其启动配置；显式撤销权限则按任务取消规则处理。

模型实际收到的项目快照、选区、引用和交接信息进入 Session 日志。前端暂存的选择状态不能成为未记录的模型上下文。

## 角色配置

“Agent 配置”从全局设置及面板的“能力与工具”进入。用户查看角色与页面映射，编辑配置草稿并发布版本；专业 agent 无权修改自身配置或发布权限变化。

| 配置项 | 规则 |
| --- | --- |
| 角色身份与页面绑定 | 稳定角色 ID、显示名称、适用页面和对象范围 |
| 模型路由 | 对话模型、推理和输出约束；需要视觉检查时验证图片输入能力 |
| 角色设定 | 专业目标、工作方式、交付要求、不可越过的权限 |
| Skills | 指定来源与版本、启用状态及适用任务；skill 内容不授予额外权限 |
| 工具 | 允许的具体操作、读写范围、结构化输出要求、审批分类 |
| MCP | 连接引用与选定工具；不因为接入服务器就开放全部工具 |
| 限额 | agent 步数、执行时限、子任务数量、模型用量和媒体制作额度分别控制 |
| 发布版本 | 校验依赖及权限变化，保存可追溯配置；新任务使用发布版本 |

模型与服务页管理供应商连接和凭据；Agent 配置管理“哪个角色能用哪些能力”。配置只引用凭据，不复制密钥到提示词、项目文档或客户端展示中。

发布前校验工具存在、provider 支持、读写范围、凭据可用性以及生成审批策略。展示实际生效的能力，不能只显示一个看似专业的角色标签。项目级覆盖只能在全局授权允许的范围内收紧或选择能力，不能扩权。

## 跨角色交接

正式交接以批准的产物和固定版本为基础：编剧提交剧本，分镜导演引用它规划镜头，生图助手引用镜头和标准资产制作关键帧，视频助手引用批准画面，剪辑助手引用批准片段。

一个角色可以提出跨角色协作任务，但不能自动扩大用户授权。任务记录交出方、接收方、目标对象、输入版本、允许操作、费用范围和完成条件。跨集修改明确列出涉及集数；付费草图也遵守制作授权，不因名称包含“草稿”而豁免。

## 授权约束

宿主依据真实角色身份和项目成员关系检查每项操作。MCP 的写入或收费工具必须通过相同的业务授权层；无法纳入授权控制的远端写操作不向专业角色开放。工具名过滤、角色提示词或 UI 按钮禁用不能替代服务端检查。

媒体提交、轮询、下载和转码仍由服务执行。模型可以准备请求与分析结果，但不会持续发消息轮询任务，也不能因切换页面重复启动生成。

生成单、内容审查和结果采用规则统一引用[功能设计](feature-design.md#人工审查)。需要的实现组件和状态持久化见[工程方案](architecture-design.md)。
