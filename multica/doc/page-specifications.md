## 专业对话工作区

创作页面统一采用中央手工编辑、右侧专业 agent 对话的布局。面板显示角色、当前对象与版本、能力与工具、对话、修改提案和输入框；批准与付费授权操作保留在中央工作区。完整角色配置和会话规则见[专业 Agent 工作区](agent-workspaces.md)。

| 页面编号 | 右侧角色 | 中央主要对象 |
| --- | --- | --- |
| 01、02 | 策划助手 | 新项目表单、故事大纲 |
| 03、04 | 编剧助手 | 分集规划、单集剧本 |
| 05 | 角色设计助手 | 角色标准图、造型与表情 |
| 06、07 | 美术助手 | 场景布局、道具与状态 |
| 08 | 分镜导演助手 | 镜头构图、景别、机位和衔接 |
| 09 | 生图助手 | 参考图、局部修改、关键帧候选 |
| 10 | 视频助手 | 首尾帧、动作方案和视频候选 |
| 11 | 剪辑助手 | 镜头、声音、字幕与时间线 |
| 12 | 连续性检查助手 | 内容差异和人工审查 |

应用建议前显示前后差异，用户可只接受部分字段。切换页面只切换专业角色与工作记录，不执行任务；在途结果保留原对象归属。00、13–16 为管理页面，不强制放置创作 agent。

## 全局项目管理

全局页面不显示某集的编辑页签。选择项目后进入该项目工作台；新项目进入故事大纲，已有项目可回到最近编辑对象。

### 00 项目首页

设计图：[全部项目](designs/00-project-home.png)。

- 入口：应用最左侧工具栏“漫剧”、左上角“返回全部项目”、项目选择器中的“全部项目”。
- 内容：封面、项目名称、当前制作阶段、具有明确分母的进度、待审数量、最近更新时间。
- 操作：新建、进入、搜索、按更新时间排序、重命名和归档；进行中与归档分开筛选。
- 创建入口：右上角“新建项目”为主入口，空卡片和空状态提供辅助入口。
- 状态：没有项目时展示创建引导；归档项目只读，恢复后才重新开放制作。进度仅依据已批准产物统计，不把生成成功计为定稿。

### 01 新建项目

设计图：[新建项目](designs/01-create-project-agent-v2.png)。

- 入口：项目首页主按钮、创建卡片、项目选择器。
- 内容：中央填写名称、构想、导入来源、画幅、集数与时长，右侧策划助手帮助提炼和填写；目标规模可暂不确定。
- 操作：“创建项目”保存规格并打开故事大纲；“取消”返回来源页面。
- 状态：校验名称和上传格式；导入失败保留已填表单并说明修正方式。防止连续点击建立重复项目。
- 授权：创建不调用生图、视频或对话生成。后续 agent 任务另行发起。

## 全剧创作

全剧规划管理整部作品，分集规划只定义各集目标和结构。单集对白与动作在单集剧本页编辑。

### 02 故事大纲

设计图：[故事大纲](designs/02-story-outline-agent-v2.png)。

右侧策划助手以完成左侧故事大纲为主要任务。显示创作职责、当前对象和“起草故事大纲 / 完善现有大纲 / 检查故事逻辑”入口；快捷入口填写需求，用户发送后才调用模型。左侧展示项目构想与大纲编辑区，助手每次读取发送时的最新草稿。模型与输入框保持可见，工作记录和配置默认折叠。

起草或改写结果包含完整大纲正文，保留未要求修改的段落，提供“应用到左侧大纲”和“忽略此大纲”。应用后左侧立即显示结果，并保存可恢复的草稿版本；分析请求只给出检查意见。已有未发送需求不会被快捷入口覆盖；锁定、归档或冲突时不能覆盖大纲。

- 入口：项目侧栏“全剧规划 / 故事大纲”。
- 内容：故事核心、主线冲突、人物弧线、世界规则引用、结构和版本。
- 操作：直接编辑、保存草稿、比较版本、让助手提出局部修改、提交审查。
- 审查：展示本次改动和影响范围；批准内容需要创建新草稿才能继续修改。
- 衔接：选中的大纲结构可作为分集规划任务的明确输入。

### 03 分集规划

设计图：[分集规划](designs/03-episode-plan-agent-v2.png)。

- 入口：项目侧栏“全剧规划 / 分集规划”。
- 内容：集数、标题、本集目标、核心冲突、结尾悬念、目标时长及状态。
- 操作：添加、排序、修改梗概、提交版本审查、打开选中集的剧本。
- 审查：检查跨集铺垫、人物认知和事件顺序；修改顺序后提示关联剧本的影响。
- 空状态：允许手工逐集添加或授权助手提出一份分集草稿。

## 共享设定

资产使用稳定身份和独立版本。共享资产与剧情中的当前状态分开保存，避免把某次换装或道具变化误当成身份改变。

### 05 角色与造型

设计图：[角色与造型](designs/05-character-wardrobe-agent-v2.png)。

- 入口：项目侧栏“共享设定库 / 角色与造型”。
- 内容：角色列表、多视角标准图、表情、身份特征、造型、声音和使用记录。
- 操作：新建角色、导入参考、提出生成方案、建立修改草稿、比较并提交定稿。
- 版本：角色身份与造型分别引用；声音配置单独保存。删除或归档已被引用对象不能破坏历史产物。
- 审查：标准图之间也需要一致性审查；新版批准后展示镜头迁移选择。

### 06 场景设定

设计图：[场景设定](designs/06-scene-library-agent-v2.png)。

- 入口：项目侧栏“共享设定库 / 场景”。
- 内容：全景、多视角参考、平面布局、固定物体、机位、灯光方案及引用场次。
- 操作：创建场景、导入参考、编辑布局与灯光草稿、创建新版本、打开引用镜头。
- 一致性：平面布局与视角图互相对应，镜头固定场景和灯光版本。
- 状态：缺少必要布局或版本待审时，可以编辑分镜草稿，但暂停依赖该版本的正式生成。

### 07 道具设定

设计图：[道具设定](designs/07-props-library-agent-v2.png)。

- 入口：项目侧栏“共享设定库 / 道具”。
- 内容：标准外观、尺寸与材质、状态变体、持有者和镜头使用记录。
- 操作：新建、导入、多状态定义、修改草稿、补充镜头开始与结束状态。
- 连续性：检查未拆与已拆、完好与损坏、左右手持物等变化是否有剧情依据。
- 审查：不明确的信息标记“待确认”，不由系统静默猜测。

## 单集制作

左侧选择某一集后，中央顶部固定“剧本 / 分镜 / 镜头制作 / 剪辑成片”四个页签。页签切换保留当前集；镜头选择只改变当前页的编辑上下文。

### 04 单集剧本

设计图：[单集剧本](designs/04-episode-script-agent-v2.png)。

- 入口：选择某集并打开“剧本”，或从分集规划进入。
- 内容：场次目录、动作、角色对白、旁白、段落 ID、引用设定和关联镜头。
- 操作：编辑场次与正文、选择段落改写、导入剧本、比较版本、提交审查、跳转关联分镜。
- 关联：镜头引用稳定段落身份和具体剧本版本；段落修改后列出受影响镜头。
- 冲突：编辑基于预期版本，遇到其他修改时保留本地草稿并要求合并。

### 08 分镜台

设计图：[分镜台](designs/08-storyboard-agent-v2.png)。

- 入口：单集“分镜”页签。
- 内容：场次筛选、镜头卡片、景别、机位、动作、时长、对白、引用与审查状态。
- 操作：添加与排序镜头、编辑构图草稿、建立图文关联、审查镜头版本、进入镜头制作。
- 右侧：分镜导演助手针对当前镜头讨论构图、景别和衔接；剧本来源、资产引用及人工批准保留在中央属性与审查区。
- 分工：批准分镜不授权付费生成；生成方案在“镜头制作”审查。

### 09 关键帧制作

设计图：[关键帧制作](designs/09-keyframe-production-agent-v2.png)。

- 入口：单集“镜头制作 / 关键帧”。
- 内容：镜头切换、当前定稿、候选版本、参考素材、局部修改区域和尝试历史。
- 操作：手工导入、局部修改、并排对比、准备生成单、批准本次生成、采用候选。
- 请求：明确要改变和保留的内容，固定引用、数量、模型、参数及额度。
- 状态：报价缺失、引用待审、额度不足或请求已变更时阻止提交并提供修正入口。采用候选不触发视频生成。

### 10 视频制作

设计图：[视频制作](designs/10-video-production-agent-v2.png)。

- 入口：单集“镜头制作 / 视频”。
- 内容：批准的首帧或其他输入、可选尾帧、动作起止、运镜、时长、分辨率、候选片段和失败原因。
- 操作：准备方案、审查生成单、查询任务、按时间点批注、采用或退回片段。
- 能力：根据供应商实际支持显示首尾帧、参考图、声音等参数；不支持时明确拒绝相关要求。
- 连续性：检查片段内变化及与相邻镜头的衔接；远端成功只产生候选。

### 11 剪辑成片

设计图：[剪辑成片](designs/11-editing-agent-v2.png)。

- 入口：单集“剪辑成片”。
- 内容：预览、素材库、视频轨、配音轨、音效轨、字幕轨、片段属性和时间线版本。
- 操作：排列与裁切片段、设置静帧运动、导入或制作声音、修改字幕、保存版本、提交粗剪审查、最终导出。
- 粗预演：允许使用标记清楚的草稿和临时声音；正式导出检查产物批准状态。
- 导出：绑定时间线与素材版本，显示画幅、分辨率、帧率、声音和字幕选项。失败保留任务记录与可重试原因。

## 审查与运行管理

审查决定作品能否定稿和请求能否执行；运行管理展示执行事实，不替代质量审查。

### 12 待我审查

设计图：[待我审查](designs/12-review-center-agent-v3.png)。

- 入口：全局导航或项目内预筛选入口。
- 内容：“内容定稿”和“生成授权”分别排队，可按项目、集、类型和状态筛选。
- 对比：中央展示文本差异、图片区域批注或视频时间点意见；右侧连续性检查助手只读分析，人工审查操作位于中央。
- 操作：批准具体版本、退回修改、审查明确选定的多个对象；展示影响范围。
- 状态：输入发生变化后提示重新加载与审查，不把旧决定套用到新请求。

### 13 生成任务

设计图：[生成任务](designs/13-generation-jobs.png)。

- 入口：全局导航或项目内预筛选入口。
- 内容：对象、项目与镜头、任务类型、状态、提交次数、授权范围、费用和事件记录。
- 操作：查看结果、查询远端、请求取消、打开对应审查项；仅在确认可安全重试时提供重新提交。
- 状态：待授权、排队、运行中、成功、失败、取消请求中、已取消、待核实分别显示。
- 恢复：提交响应不明时先核实；费用未结算继续占用预留额度，不展示伪精确进度。

## 服务与设置

供应商连接属于全局配置，项目预算和制作规格属于项目。某服务连接成功不会自动获得项目生成授权。

### 14 模型与服务

设计图：[模型与服务](designs/14-model-services.png)。

- 入口：全局侧栏“模型与服务”。
- 内容：对话、图像、视频和声音服务，连接状态、凭据引用、能力与费率配置。
- 操作：添加、检查连接、修改连接信息、选择模型、配置费率；通过 Agent 配置选择哪些角色可使用已连接服务。
- 凭据：只显示掩码或引用；不显示原始密钥，不将凭据写入项目内容或图像提示词。
- 能力与费用：明确支持与不支持的功能。费率在此配置，项目设置只配置预算；服务能力与密钥存储方式需依据实际 provider 实现验证。

### 15 项目设置

设计图：[项目设置](designs/15-project-settings-v2.png)。

- 入口：项目侧栏底部“项目设置”。
- 内容：基本信息、画幅与目标规模、审查策略、预算、提交次数、并发限制、版本迁移策略和归档。
- 操作：保存配置、取消修改、归档与恢复项目。
- 权限：预算和审查规则由创作者修改，agent 不能自行扩大。
- 生效：设置更新影响新授权；已有授权不隐式扩大。需要收紧在途行为时单独展示撤销或停止操作及远端限制。

### 16 Agent 配置

设计图：[Agent 配置](designs/16-agent-configuration.png)。

- 入口：全局“设置 / Agent 配置”，或专业面板“能力与工具 / 查看配置”。
- 内容：角色列表、模型路由、角色设定、Skills 来源与版本、MCP 连接及具体工具选择、页面绑定、生效范围和权限变化。
- 操作：编辑配置草稿、校验依赖、查看当前生效配置、发布新版本。
- 约束：配置由用户发布；agent 无权修改自身能力。连接一个 MCP 服务不等于开放全部工具。
- 生效：新任务固定发布版本，在途任务保留原配置；显式撤销权限另行处理。未配置或失效依赖不能显示为可用。
- 区分：模型与服务管理连接和凭据，此页管理专业角色如何使用这些能力，不重复保存密钥。

## 通用交互

文字、图片与视频批注关联具体版本。界面保留当前项目、集、对象和版本的可见标识，避免对错误对象操作。

所有修改都有保存中、已保存、失败及冲突反馈。危险或不可逆操作说明范围；可恢复操作提供恢复路径。首版优先支持键盘导航、可读对比度与明确禁用原因。

当前效果图的构图与导航细节存在生成差异，例如重复项目选择器、局部嵌套集数、示例日期及品牌标识不完全统一。实现采用[功能设计](feature-design.md)规定的导航与审批语义，不逐像素复制这些差异。字幕时间、镜头时长和演示费率也需要用真实数据渲染。
