# 文本创作工作台

## 概览

工作台沿用最左侧“漫剧”入口，提供策划、编剧对话、字段提案、角色配置及人工内容审查。对应[开发计划](development-plan.md)的 S2 实现范围；真实模型效果仍需配置文本供应商后验收。页面和权限依据[专业 Agent 工作区](agent-workspaces.md)及[页面规格](page-specifications.md)实现。

## 创作与提案

新建项目和故事大纲右侧使用策划助手，分集规划和单集剧本右侧使用编剧助手。打开页面只恢复工作记录，不发送消息。输入需求后点击“发送”或按 Enter，Shift+Enter 换行；未发送文字在当前浏览器会话内按对象保留。正在运行的任务固定到启动时的项目、单集、内容版本及角色配置，切页不会改变它。

助手返回说明及修改提案。先展开修改前内容，与修改后内容比较，再勾选需要的字段，选择“应用选中字段”。应用建立草稿版本，不批准内容。锁定字段必须先解锁；旧提案与后续手工修改冲突时保留现有内容。忽略字段不会修改项目。

创建表单有独立草稿身份。可以保存表单并从首页恢复；发送给策划助手前也会先保存。只有点击“创建项目”才生成正式项目，同一已保存创建身份只发布一次。未保存表单仍需在关闭页面前保存或导出。

## 配置与会话

首页和助手面板的“Agent 配置”列出九个专业角色。当前启用策划与编剧，其余角色明确显示制作能力未开放。配置可选择全局默认模型，或填写具体供应商及模型，调整角色设定、输出 Token、步骤和执行时限，选择实际登记的 Skills 与受控只读工具，再显式发布版本。

新配置使用新的工作记录版本，既有会话保持原身份和模型选择，在途任务不换配置。Skills 正文在首次任务时冻结，不授予工具权限。MCP 只开放宿主登记的具体只读操作，不因连接服务器而开放全部工具。供应商鉴权最终由真实请求验证；配置发布不代表已经成功调用供应商。

模型收到的项目快照、需求、技能正文和批准引用写入对应 Session 日志。角色不能通过普通聊天绕过工作区任务，也没有应用草稿、批准内容和授权媒体制作工具。

## 人工审查

保存大纲、分集或剧本后，选择“提交内容审查”。从“待我审查”明确选中记录，查看待审版本及上一批准版本，填写意见，再选择“批准此版本”或“退回修改”。批准后不会自动选中下一项。

审查固定到提交时的项目版本。项目已有更新或已经归档时不能批准旧记录，需要重新提交当前内容。最终决定不可覆盖；内容批准不授权付费生成，也不自动启动分镜或媒体制作。

## 恢复与限制

数据库模式 2 保存角色版本、工作区、任务、提案、创建表单及审查。模式 1 首次升级前自动生成一致备份；备份位置和恢复方法见[项目服务](../../packages/multica/studio-core/README.zh.md)。恢复完整专业工作记录时需要同时恢复数据库及其 Session 日志。

重新打开工作区会恢复历史与待处理提案。任务中断不自动重新提交；只有确认所属进程已退出才会标记中断。其他存活进程拥有的任务不能在本进程取消。传输结果不确定时，“重试提交”沿用原请求身份及输入；“停止等待”不代表原任务已经取消。

当前尚未交付共享资产、参考图、分镜、关键帧、视频、声音和剪辑成片。媒体后端、测试额度及真实模型验收凭据尚未确定；这些依赖未满足前不标记完整制作链已完成。开发模型 Token 无可读取的精确请求账本，不能用测试次数推算精确用量；本次没有发起媒体付费调用。

故事大纲页提供起草、完善和逻辑检查快捷入口，点击后先填写需求，发送时包含左侧最新草稿。起草和改写提案提供“应用到左侧大纲”，点击后更新编辑区并保存草稿版本，可从版本历史恢复；内容审查单独提交。
