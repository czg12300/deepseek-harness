# @deepseek-ai/dsh-client-ui-multica

[English](README.md) | 中文

## 概述

从左侧栏打开“漫剧”，管理项目、Markdown 剧本、制作画布和导入素材。可以手工编写剧本，或请求策划与编剧提案。确认已保存的剧本后，可创建逐集或整片制作单位。人工审查与制作分开进行。

助手面板按目标保留未发送需求，展示任务状态、配置版本、选定技能和受控工具。创建页展开“草稿导出与策划助手”即可使用策划助手。向策划助手发送创建需求前会先保存独立表单；建立正式项目仍是单独操作。查看前后值并选择字段后才能应用。后续手工修改和锁定字段受到保护，应用不等于批准。审查中心要求选择已保存版本，再单独作出人工决定。

Agent 配置列出全部九个角色和实际能力。宿主运行时启用策划和编剧，其余角色保持未开放。发布配置后，后续任务打开绑定到新版本的对话。已有对话仍可读取，在途任务保留原角色和对象。

专业助手输入框复用主对话的卡片和模型菜单。模型及推理程度按创作目标保留，并与每次提交的需求一起固定，包括结果不确定时的网络重试。Enter 发送，Shift+Enter 换行；输入法组字期间不会发送。任务运行时显示停止按钮。

未显式选择草稿模型时，重新打开工作区会恢复最近一次已完成任务的模型和推理程度；失败的选择不会替换它。加宽后的助手面板让消息独立滚动，并保持输入框可见。


故事大纲助手根据当前项目和本地大纲提供起草、完善及逻辑检查入口。快捷入口只填写输入框，不发送，也不替换未发送需求。大纲提案展示完整替换正文，用户明确点击后更新左侧编辑区并保存草稿版本；锁定和内容过期检查仍然生效。工作记录与设置折叠展示，为创作对话留出空间。

## 使用本包

“新建作品”在项目列表或当前项目上方打开居中弹窗。右上角关闭按钮、Escape 和遮罩均可关闭弹窗，创建草稿会保留供再次打开。表单在视口内滚动，创建按钮保持可见。

一部作品对应一个文件夹。在创建表单的作品名称下方选择新的或空的文件夹，选中后直接绑定当前作品。作品卡片显示各自的保存路径。点击首页右上角或“新建或打开项目”卡片中的“打开项目”，选择已有文件夹，即可在另一台设备恢复其内容和专业对话。取消选择会留在首页，打开失败会在首页显示错误。绑定文件夹的作品卡片右上角提供“删除”按钮；确认后仅移除本机项目列表登记，即使目录或数据库缺失也能删除。该操作不保存草稿、不关闭项目或停止任务，内存中的草稿继续保留；通过“打开项目”可重新登记可访问的文件夹。项目设置提供完整备份副本。关闭操作保存当前文本缓冲、停止本地专业任务，并等待文件释放后才提示可以复制目录或弹出硬盘。保存失败时保留编辑器并显示宿主错误。模型凭据仍在各设备分别配置。

“全部项目”和“演员库”是同一漫剧工作台中的两个 Tab。切换时保持浏览器位置与当前所选演员库。可新建演员库、添加头像和全身参考图、按姓名搜索、按时代及地区筛选、导出 ZIP，或将归档导入并合并到所选库。宿主服务拥有 SQLite 数据库和文件；浏览器只把用户选择的图片和归档字节传给类型化 Remote 接口。

进入有独立文件夹的项目后，左侧目录展示故事 Markdown、制作单位和项目资产。选择剧本可在中间阅读，右侧助手提供大纲、人物小传或单集提案。人物建议保存到独立 Markdown 文档，不覆盖项目大纲。“编辑文档”保存完整 Markdown；“新增分集”创建新的项目修订和剧本文件。明确确认剧本要求已保存且非空的大纲，以及至少一集非空剧本。剧本内容改变后确认失效。制作单位打开可拖动节点的画布，右下角悬浮文本助手输入框；只有明确添加，回复才成为文本节点。可向制作单位导入不超过 16 MiB 的 PNG、JPEG、WebP、MP4、MP3、WAV 或 OGG 文件。资产目录可筛选媒体，并在弹窗中缩放图片或播放音视频。

[Web bundle](../../bundle/web-app/README.zh.md)将此浏览器插件与[项目服务](../../multica/studio-core/README.zh.md)一同挂载。本插件没有配置字段。英文侧栏入口为“Comics”，中文为“漫剧”；侧栏收起时仍保留带提示的图标入口。

填写一句构想或提供来源剧本即可创建项目。“更多设置（可选）”包含名称与制作规格；初始画幅为 16:9，集数与时长暂不确定。名称留空时使用去除首尾空白后构想的前 50 个 Unicode 码点；仅提供来源正文时使用当前语言的“未命名作品”。所有字段仍可在项目设置中编辑。导入 UTF-8 编码的 `.txt` 或 `.md` 文件会将来源正文复制到草稿，不会生成分集。项目侧栏用于选择大纲、分集列表、各集剧本、设置和历史。项目设置还提供重命名、归档和恢复。

每次保存都根据草稿的预期版本提交完整项目。冲突时会同时展示当前已保存内容和本地草稿。用户可以导出本地草稿、明确放弃草稿并加载当前已保存版本，或确认以本地内容建立新版本。确认本地内容会替换完整远端项目内容，不是字段级合并。归档项目在恢复前保持只读。

未保存草稿与选中页面在插件生命周期内跨项目导航和主面板重新挂载时保留。刷新或关闭浏览器前请先保存或导出。导出会下载本地 JSON 草稿；它不是完整数据库备份，也不是项目导入格式。

## 理解实现

<details>
<summary>实现细节——点击展开</summary>

浏览器入口通过现有插槽注册 `multica` 主面板和侧栏图标。声明式 store 保存导航与未保存草稿；独立的 Remote 查询模型通过注入的框架 hook 发布观察到的已保存项目。请求在导航时保持原项目身份。读取顺序与版本校验会拒绝过期观察结果，资源释放后则停止发布迟到结果。宿主服务仍负责持久化与归档状态的权威判断。

本插件不发布 `./invariant` 配套模块：它负责查看状态和待保存草稿，持久化项目关系由宿主检查。[版本决定](../../../.agents/notes/implemented/architecture/2026-09-10-multica-project-revisions.zh.md)说明项目级版本管理与 Session 分工。

</details>

<a id="model-experience"></a>
## 模型体验

间接影响：显式对话提交将捕获的本地输入和需求发送到[专业运行时](../../multica/studio-agents/README.zh.md)，由它管理模型消息及 Session 日志。导航和人工审查不提交模型请求。

#### KV Cache 影响

无；本插件不会组装或发送供应商请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

独立文件夹项目提供 Markdown 剧本、制作画布、导入素材和项目管理。

- 未保存草稿位于内存中；浏览器刷新、插件替换或关闭页面都会丢弃尚未保存或导出的草稿。
- 历史与保存冲突以完整项目为单位，包括全部单集草稿。不提供自动字段合并或独立单集版本计数。
- 其他窗口的修改在读取或保存项目时发现；服务不提供实时项目变更订阅。
- 模型生图、生视频、生音频、预算、时间线剪辑与成片导出尚未开放。画布助手通过现有策划或编剧目标提供文本建议；项目媒体仅来自导入文件。演员参考图和演员库 ZIP 不会生成项目媒体。助手未配置时展示实际失败。
