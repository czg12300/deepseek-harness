# @deepseek-ai/dsh-client-ui-multica

[English](README.md) | 中文

## 概述

从左侧栏打开“漫剧”，管理漫剧项目和不可变文本版本。手工编写大纲和剧本，或向策划、编剧助手请求提案。明确选择提案字段，再将保存内容提交人工审查。可以恢复已保存创建表单、发布角色配置，并将对话固定到原始对象。媒体制作仍未开放。

助手面板按目标保留未发送需求，展示任务状态、配置版本、选定技能和受控工具。创建页展开“草稿导出与策划助手”即可使用策划助手。向策划助手发送创建需求前会先保存独立表单；建立正式项目仍是单独操作。查看前后值并选择字段后才能应用。后续手工修改和锁定字段受到保护，应用不等于批准。审查中心要求选择已保存版本，再单独作出人工决定。

Agent 配置列出全部九个角色和实际能力。宿主运行时启用策划和编剧，其余角色保持未开放。发布配置后，后续任务打开绑定到新版本的对话。已有对话仍可读取，在途任务保留原角色和对象。

<a id="use-this-package"></a>
## 使用本包

[Web bundle](../../bundle/web-app/README.zh.md)将此浏览器插件与[项目服务](../../multica/studio-core/README.zh.md)一同挂载。本插件没有配置字段。英文侧栏入口为“Comics”，中文为“漫剧”；侧栏收起时仍保留带提示的图标入口。

填写一句构想或提供来源剧本即可创建项目。“更多设置（可选）”包含名称与制作规格；初始画幅为 16:9，集数与时长暂不确定。名称留空时使用去除首尾空白后构想的前 50 个 Unicode 码点；仅提供来源正文时使用当前语言的“未命名作品”。所有字段仍可在项目设置中编辑。导入 UTF-8 编码的 `.txt` 或 `.md` 文件会将来源正文复制到草稿，不会生成分集。项目侧栏用于选择大纲、分集列表、各集剧本、设置和历史。项目设置还提供重命名、归档和恢复。

每次保存都根据草稿的预期版本提交完整项目。冲突时会同时展示当前已保存内容和本地草稿。用户可以导出本地草稿、明确放弃草稿并加载当前已保存版本，或确认以本地内容建立新版本。确认本地内容会替换完整远端项目内容，不是字段级合并。归档项目在恢复前保持只读。

未保存草稿与选中页面在插件生命周期内跨项目导航和主面板重新挂载时保留。刷新或关闭浏览器前请先保存或导出。导出会下载本地 JSON 草稿；它不是完整数据库备份，也不是项目导入格式。

<a id="understand-the-implementation"></a>
## 理解实现

<details>
<summary>实现细节——点击展开</summary>

浏览器入口通过现有插槽注册 `multica` 主面板和侧栏图标。声明式 store 保存导航与未保存草稿；独立的 Remote 查询模型通过注入的框架 hook 发布观察到的已保存项目。请求在导航时保持原项目身份。读取顺序与版本校验会拒绝过期观察结果，资源释放后则停止发布迟到结果。宿主服务仍负责持久化与归档状态的权威判断。

本插件不发布 `./invariant` 配套模块：它负责查看状态和待保存草稿，持久化项目关系由宿主检查。[版本决定](../../../.agents/notes/implemented/architecture/2026-09-10-multica-project-revisions.zh.md)说明项目级版本管理与 Session 分工。

</details>

<a id="model-experience"></a>
## 模型体验

间接影响：显式对话提交将捕获的本地输入和需求发送到[专业运行时](../../multica/studio-agents/README.zh.md)，由它管理模型消息及 Session 日志。导航和人工审查不提交模型请求。

#### KV Cache 影响

无；本插件不会组装或发送供应商请求。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

项目基础版提供手工文本编辑和项目管理。

- 未保存草稿位于内存中；浏览器刷新、插件替换或关闭页面都会丢弃尚未保存或导出的草稿。
- 历史与保存冲突以完整项目为单位，包括全部单集草稿。不提供自动字段合并或独立单集版本计数。
- 其他窗口的修改在读取或保存项目时发现；服务不提供实时项目变更订阅。
- 共享媒体资产、生成、预算和剪辑导出尚未开放。助手未配置时展示实际失败，不合成成功模型回复或制作结果。
