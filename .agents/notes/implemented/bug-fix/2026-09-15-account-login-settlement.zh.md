# Agent Note: 账号登录结果与启用恢复

Status: implemented

[English](2026-09-15-account-login-settlement.md) | 中文

## Problem

OAuth 回调页会在 Host 交换授权码、保存凭证之前确认收到授权码。看似主动取消的超时或通用失败提示无法解释账号为何仍未连接。已保存的授权凭证也可能在启用失败后继续存在。

## Decision

账号登录结果使用固定的公开原因码，区分授权或保存失败、启用失败和登录等待超时。厂商异常文本保持私有。默认交互等待时间为 15 分钟，与当前安装的 ChatGPT 设备码有效期一致，并保留配置能力。用户主动取消是独立结果。

ChatGPT 重试利用已保存的授权凭证完成启用。设置页为已授权但未启用的账号提供此操作，并在卡片上方保留最终反馈。连接提交后立即更新卡片，并使旧列表读取失效，避免其他 Provider 的状态查询延迟连接状态显示。[独立账号决策](../architecture/2026-09-09-isolated-third-party-accounts.zh.md)继续负责 Provider 隔离、原生会话和凭证存储，不被取代。

## Alternatives considered

- 关闭本机代理：经代理探测成功并不能证明它是登录失败的原因，直接访问也可能遭到拒绝。
- 暴露厂商异常文本：令牌响应和原生错误可能包含凭证。
- 每次启用失败都重复浏览器登录：放弃了可用的已保存授权凭证，也增加用户操作。

## Consequences

更长的登录窗口会让已放弃的尝试存活更久，但仍有主动取消和有界截止时间。原因码指出失败阶段，不诊断所有远端拒绝原因。无密钥 Web 测试仅替换外部 OAuth 响应，执行真实授权、凭证、设置和浏览器链路。真实账号授权仍需要用户在浏览器中操作；这些测试不能证明某条 VPN 线路或某个账号会被接受。
