# Agent Note：专业任务保留不可变目标，并要求人工应用

Status: implemented

[English](2026-09-11-multica-professional-tasks.md) | 中文

## 问题

专业对话可能比发起它的页面存活更久。跨角色复用普通聊天可能将运行中结果移到其他项目、静默改变身份、开放继承的写工具，或覆盖期间的手工修改。

## 决策

[项目服务](../../../../packages/multica/studio-core/README.zh.md)持久化角色版本、目标绑定工作区、冻结任务输入、提案及人工审查。工作区在 Agent 执行前预留独立 Session ID。发布角色配置建立新工作区版本。请求 ID 使不确定传输重试具备幂等性；一个工作区只允许一个运行中任务。

[专业运行时](../../../../packages/multica/studio-agents/README.zh.md)将每项捕获任务记录为普通用户消息内容，并复用共享结构化输出捕获协议。持续 Agent 作用域守卫拒绝无关聊天和继承工具。安全 `multica` 预设不包含写能力。选定技能贡献文本；可信上下文工具只在捕获任务范围内读取。

提案应用将选定字段同时与本地修改前值及不可变已保存基础版本比较，校验跨范围字段锁，并原子追加草稿版本，不批准内容。审查决定指定具体已保存目标版本，只能通过人工操作作出。创建表单具有独立保存身份，并且只发布一次正式项目。创建页接受一句构想或来源剧本，不要求填写制作规格或名称。用户创建项目时才推导未填写的名称；保存未完成的创建草稿会原样保留字段。可选设置与策划助手默认折叠，手工创建无需配置助手。

本决策扩展[项目版本决策](2026-09-10-multica-project-revisions.zh.md)，不将项目状态移入 Session 历史。数据库管理编辑和审查决定；Session 管理准确的模型可见输入与输出。

## 考虑过的替代方案

**仅依靠身份提示词限制。** 指令不能阻止继承工具写入。作用域注册、执行守卫和独立人工 API 共同约束支持的操作。

**直接应用模型补丁。** 即使已保存版本未变，晚到回复仍可能引用旧本地草稿。不可变字段比较同时保护本地及已持久化编辑。

## 后果

每项任务存储完整选定文本，并在 Session 中重复，增加存储和模型输入。恢复不盲目重提中断任务。不能在此取消其他进程中的活动任务；不确定进程归属保持可见。模式 1 数据库迁移到模式 2 前需要一致备份。

只启用策划和编剧执行。媒体授权、资产、生成后端和连续性报告保留各自后续阶段要求；登记角色或 MCP 来源不会授予这些能力。
