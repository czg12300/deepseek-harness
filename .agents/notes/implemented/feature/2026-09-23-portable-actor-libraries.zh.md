# Agent Note: 可携带的演员库

Status: implemented

English | [中文](2026-09-23-portable-actor-libraries.md)

## Problem

演员及视觉参考需要独立于任何漫剧项目保存。演员库应携带自己的素材，导入其他演员库时不能覆盖本地的演员版本。

## Decision

每个演员库是设备漫剧数据库同级 `actor/` 目录下的独立文件夹，包含版本化清单、SQLite 数据库和 `assets/` 中按内容哈希命名的参考图。复制后，库和演员 UUID 保持不变。项目版本和 Session 存储不拥有演员记录。

漫剧全局工作台在同一浏览器位置切换“全部项目”和“演员库”两个 Tab。演员库 Tab 使用与项目列表相同的多语言字典和黑白语义颜色，支持多个库目录、演员搜索和筛选、手动编辑、两张参考图，以及有限大小的 ZIP 导入导出。

导入在写入目标库前校验压缩包条目、解压大小、SQLite 身份和图片哈希。合并按演员身份及内容与图片指纹判断。相同内容跳过；同 ID 但内容不同的版本以新演员 ID 复制，保留目标版本。来源记录使重复导入不会增加副本。仅姓名相同不构成合并依据。

## Alternatives considered

**将演员保存在项目数据库中。** 这样无法独立复制或复用一个演员库。

**按展示名称合并，或覆盖目标 UUID。** 名称不是稳定身份，覆盖会丢失创作者的本地版本。

## Consequences

目前的 ZIP Remote 传输对压缩大小、解压大小、条目数量和单张图片设有明确上限。超限归档在安装前失败；这条路径不声称支持超大素材库。项目侧使用演员库演员仍需后续明确的绑定和版本规则。
